# FlowCast 📈

Personal financial analytics for people who want straight answers about their money.

## Live
🌐 [myflowcast.lovable.app](https://myflowcast.lovable.app) / Landing page  
🚀 [tryflowcast.lovable.app](https://tryflowcast.lovable.app) / App

## What it does
Drop in your bank export. FlowCast reads it, breaks down where your money went, 
spots patterns you'd miss, and projects where you're headed up to 24 months out.

No bank login required. Works with any CSV or Excel file from Chase, BofA, 
Wells Fargo, Citi, or any US bank.

## Features
- Spending breakdown by category, merchant, and day of week
- 6–24 month forecast (Prophet + ARIMA, best model auto-selected)
- Budget tracking with overspend alerts
- Anomaly detection flags transactions outside your normal pattern
- Subscription detector finds recurring charges you forgot about
- Financial health score with personalized recommendations

## Stack
**Frontend** : React, TypeScript, Tailwind CSS  
**Analytics** : Python, Prophet, statsmodels, pandas  
**Hosting** : Lovable, GitHub

## Target
Built for US users managing personal finances or running a small business.
